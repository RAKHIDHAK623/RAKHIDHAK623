# 🚀 Featured Project

## 🎓 CampusSkillSwap

> **Learn. Share. Connect. Grow.**

CampusSkillSwap is a campus-based **skill exchange platform** designed to connect students who want to learn with students who can teach.

### ✨ Key Features

* 🔐 Role-based authentication
* 👤 Student profiles
* 🔎 Skill discovery & search
* 🔄 Skill exchange requests
* ✅ Accept / reject exchange requests
* 🔔 Real-time notifications
* 📊 Personalized dashboard
* 📍 Campus information & map
* 🔒 Secure authentication
* 🗄️ Persistent database storage

### 🏗️ Architecture

```text
                    ┌───────────────────┐
                    │      Student      │
                    └─────────┬─────────┘
                              │
                              ▼
                    ┌───────────────────┐
                    │    HTML / CSS /   │
                    │    JavaScript     │
                    └─────────┬─────────┘
                              │
                    ┌─────────┴─────────┐
                    │                   │
                    ▼                   ▼
             ┌──────────────┐    ┌───────────────┐
             │   Firebase   │    │ Spring Boot   │
             │     Auth     │    │     API       │
             └──────────────┘    └───────┬───────┘
                                         │
                                         ▼
                                  ┌─────────────┐
                                  │    MySQL    │
                                  └─────────────┘

                         Firebase Realtime DB
                                  │
                                  ▼
                          Live Notifications
```
